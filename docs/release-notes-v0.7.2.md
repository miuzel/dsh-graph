# dsh-graph v0.7.2 Release Notes

> 发布日期：2026-08-28（计划）
> 前序版本：v0.7.1
> 主题：模型元数据、实时状态与统一执行派发

## 本版本变更

- **模型元数据（g-194）**：目标、执行尝试与主管状态保留并展示 provider/model 元数据，便于审计和交接；相关 schema、REST 与看板展示保持一致。
- **实时状态体验（g-195/g-200）**：看板实时面板与会话钩子更新，运行中的目标状态和主管信息更及时、可读，并避免上下文卡片重复展示。
- **统一执行派发（g-202）**：`graph_start_attempt` 统一目标执行与上下文卡片收集派发流程；卡片收集自动生成完整 brief 并绑定卡片，且保留执行 brief。
- **目标卡片刷新（g-198）**：新增卡片后即时刷新目标详情，避免必须手动重载。
- **发布包依赖**：host 发布包显式声明 `yaml` 运行时依赖。

## 兼容性与升级

从 v0.7.1 升级无需数据迁移。既有 `.dsh-graph` 目标、卡片和事件流继续可读；新增模型元数据与派发事件按增量字段兼容旧数据。若回退到 v0.7.1，新字段不会破坏既有数据，但新展示能力不可用。

## 已知限制

- 客户端仍为由模块化源文件构建的单文件 `lib/client.js`。
- 测试实例须使用独立 DSH_HOME、workspace 与可写 npm/pnpm store，避免污染主实例。

## 发布边界

本次仅提交发布准备，不执行 `npm publish`、`git tag` 或 `git push`。发布前请由负责人复核清单、确认 npm 包白名单及版本范围后手动发布。
