## 目标描述

用 dsh-graph 自带的简单记忆管理取代已下线的 mnemon_runtime_memory（负责人 2026-08 指示：mnemon 太贵）。

记忆 = 事件流里的持久事实（R-02 只追加），分两类：
- **project**：项目/环境事实、决策、约定、工具坑、可复用教训（对应 mnemon 的 MEMORY）；
- **user**：负责人偏好、沟通风格、pet peeves（对应 mnemon 的 USER）。

能力（graph 工具 + core op，均事件先行）：
1. `graph_memory_add`：新增一条独立事实（kind=project/user，importance 可选）；
2. `graph_memory_replace`：修正/合并已有条目（用短唯一 old 片段定位）；
3. `graph_memory_remove`：负责人明确撤回或证实过时后才删（不能仅因"最近没提"）；
4. `graph_memory_recall`：按关键词检索返回匹配条目（供 supervisor/执行子代理引用）。

存储与注入：
- 落 `.dsh-graph/memory/memory.jsonl`（事件流，一条一 JSON 行）；既有 `memory/long-term/*.md` 长期记忆并入或保留为引用；
- supervisor 每轮把相关记忆注入（按当前任务关键词匹配），并遵守"写入前先对照现有条目、只存不猜不记临时进度"的纪律；
- 沉淀流程沿用：目标交付时提炼长期记忆，条目带 source_goal 引用。

技能沉淀（原 g-105 范畴保留）：supervisor 重复模式发现 → 提议 skill，走 g-103 版本 supervisor 机制。

## 质量判据

1. core 新增记忆 op（add/replace/remove/recall），事件先行，落 .dsh-graph/memory/memory.jsonl；readMemory 按关键词检索
2. host 注册 4 个 graph_memory_* 工具（add/replace/remove/recall），返回值无损 JSON
3. supervisor-guide 增记忆纪律：写入前对照现有条目、只存不猜不记临时进度、remove 仅限明确撤回/证实过时；每轮按任务注入相关记忆
4. 核心测试不回归（含新增记忆 op 测试）
