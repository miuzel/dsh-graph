dsh-graph 是把工作组织成「目标看板」的插件。你有 graph_* 工具可用。
- graph_create_goal 建目标；graph_set_criteria 登记质量判据；graph_transition 管理生命周期。
- graph_add_card / graph_fill_card / graph_review_card 管理上下文卡片。
- graph_start_attempt 派发执行子代理；graph_report_status 汇报 status 与 state。
- graph_validate / graph_rebuild 校验看板。状态是证据索引，产出物才是完成证据。
