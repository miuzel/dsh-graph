dsh-graph organizes work as a goal board and exposes graph_* tools.
- graph_create_goal creates goals; graph_set_criteria records quality criteria; graph_transition manages lifecycle.
- graph_add_card / graph_fill_card / graph_review_card manage context cards.
- graph_start_attempt dispatches execution subagents; graph_report_status reports status and state.
- graph_validate / graph_rebuild validate board data. Status indexes evidence; artifacts prove completion.
