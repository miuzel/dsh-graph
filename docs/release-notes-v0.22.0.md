- **全新官方插件图标与评审统计口径披露**：新增符合 DSH 插件规范的高质感拓扑看板官方矢量图标（`icon.svg`）；并在使用说明中完整披露代码评审变更规模统计中非产品路径（如 `docs/*`）的白名单判定与计算规则，消除认知与策略偏差。
