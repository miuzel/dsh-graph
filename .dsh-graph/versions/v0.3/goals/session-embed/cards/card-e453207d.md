## 1. client 插件可 inject 的服务
动态 client 包拿到 cordis-client-runner facade ctx，可 inject 任何客户端 root 已提供服务：文档化 slots/theme/timer/locale/sessions/workspaces/layout；技术上还有 connection/remote/typert/modelDirectories/clientModules 等。facade 按 inject 声明门控（dsh-cordis-client-runner/lib/client.js:319-349），guardedService 转发全部方法（:235-245）。sessions 提供点 dsh-client-runtime/lib/client.js:8948。dsh-graph 现状仅 inject [slots]（lib/client.js:393）。

## 2. 会话实时状态
命令式：sessions.binding(id).session，uSES 契约 subscribe(:7445)+getSnapshot(:7452)，快照含 chat/nodes/partial/running/queue/subagent/openState（buildSnapshot :7695-7728）。流式增量在 chat.legacy.partial（:7709），底层 assistant/chunk 的 text-delta/reasoning-delta/tool-call-delta。注意：openState!=='open' 时活事件被丢弃（:7657），必须先 session.open()（:7374 幂等，拉尾页50条）。token/上下文走投影 faceOf('tokenUsage'|'contextPressure'|'contextBreakdown')（ProjectionValueStore :5732，dsh-token-meter/lib/index.js:216-227，注册:419-422）；投影推送不要求 open（manager 无条件落 store :8303-8306）。当前模型无投影，走 connection.api.sessions.models({sessionId})（dsh-client-connection/lib/client.js:6286）。

## 3. 会话目录
sessions.list 快照 store：{ids,byId,current,phase,subagentsByParent,jobsBySession}（:8908-8916）。子代理目录需 setSubagentCatalogOpen(parentId,true)+refreshSubagents(parentId)；RPC api.subagents.list({parentSessionId})（:6296）。地址 subagentAddress(id)/openSubagent(address)。

## 4. 发送指令与多模态
统一入口 binding(id).session.prompt(content, mode, signal?)（:7196-7257），mode:'queue'|'steer'。continuable 子代理自动路由 api.subagents.prompt 且仅文本——含图片返回 SUBAGENT_IMAGE_UNSUPPORTED（:7218-7225，源码级硬限制无替代）；one-shot 只读。顶层会话支持 image/png|jpeg|webp|gif base64。中断 session.cancel()；队列 updateQueue；斜杠命令 session.command(line)；读图 readAttachment。最近记录：open() 后读快照 chat.nodes，或 api.subagents.history({parentSessionId,childSessionId,mode,beforeSeq?,maxMessages?})（schema :6038-6043）。

## 5. 权限/安全
facade 是 API 纪律而非安全边界（:201-203），无 RPC 白名单：inject connection 可调全部命名空间（sessions/subagents/goals/settings/credentials/llm 等，方法表 :6281-6360）。硬限制：ctx 动词白名单、服务返回 cordis Context 被拒（影响 sessions.scope，binding 不受影响）、ctx 只读、浏览器 timer 全局禁用（timer 系需 inject timer）。

## 落点
看板卡片 inject [slots,sessions,connection] 即可实现全部需求；唯一不支持=向子代理发图片（只能在父会话侧提示）。
