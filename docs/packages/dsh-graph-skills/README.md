# dsh-graph-skills

dsh-graph 的 Agent 技能包：

- `dsh-graph` —— 看板用法（`graph_*` 工具）
- `dsh-graph-supervisor` —— 主管工作指南（目标生命周期、判据门禁、人工 gate）

```bash
npm install -g dsh-graph-skills
dsh-graph-skills                 # 装到 ${DSH_HOME:-~/.dsh}/skills
```

安装脚本**不覆盖**已存在的同名技能（除非 `--force`）。完整说明见 **INSTALL.md**。
