## 分类结论

- **可先验证的纯逻辑**：搜索归一与匹配、分区 key、模块入口投影；下一层才是表单 draft/diff 与 i18n 字典/插值。现文件含闭包引用或副本对账约束，“可复用”不等于“现在可直接发布”。
- **DSH adapter / facade**：REST routes、可信身份、配置持久化、scope 选择、宿主能力核验、locale 生命周期、文件/会话导航。原工具与 REST 形状保持不变。
- **DSH Web/Cordis 专有**：module loader、React 注入、slots.inject/register、settingsScope/remote.settings、connection.api、sessions/workspaces registry。保留现席位和迟到服务降级。
- **暂不可整组件搬迁**：kanban、goal/settings modal、card drawer、主管条、live panel；它们同时使用 React 闭包、网络、会话、DOM、全局翻译和交互状态，不能靠改 import 就成为跨宿主组件。
