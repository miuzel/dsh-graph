### 全部当前 core 源模块的直接内部边与可迁移边界

此表按顶层静态 import 盘点，不含测试；无 DSH SDK import 不等于无 DSH 语义。

| 模块 | 直接内部依赖 | 拟归属 / 阻碍 |

## 3. 拟议边界（不建立包）

- **domain/core**：目标/判据/状态/引用/纯策略；接受值，返回值或明确错误，不启动会话，不认识 GUI/SDK、不猜宿主权限。
- **application + file-store**：命令编排、可信身份、事件先行、现有 Node 文件事务/路径兼容；先保留原实现，由窄入口委托，不重写 WAL/锁。
- **skills assets**：角色规范 + 命令语义 + 能力缺失分支；从 manifest 注入具体宿主语法。公共 core 不依赖提示词资产存在才可 import。
- **host-adapter**：工具/会话/审批/执行生命周期/UI/配置输入；没有 executor 的宿主也能读写人工看板。MCP 是传输角色，不是第五种执行引擎。

包名、导出路径、Node 最低版本、审批策略尚未冻结；禁止据本文先建 packages 或把现有工具名统一替换成新命名。

## 4. 渐进迁移顺序、独立验证和回滚

| 阶段（均另派实现） | 范围/独立验收 | 回滚边界 |
|---|---|---|
| 0 人工冻结 | 确认契约、包边界、首个提取范围；逐条登记裁决 | 只撤设计，不改任何运行态 |
| 1 最小纯提取 | 仅 model + machine（保留原路径兼容 re-export）；零新增依赖、与 SDK/fs/asset 无依赖；相同输入输出/错误、frontmatter/body roundtrip、非法边/缺判据负向测试；原 DSH 整套件仍必须全绿 | 一个源代码提交回退；不改磁盘格式，不要求数据降级 |
| 2 窄应用入口 | 首选只读 snapshot/goal query 委托现有 ops，保持工具与 REST 输出；异常/未初始化均不隐式 init | 入口切回原 ops；旧 client 无需变更 |
| 3 命令/身份端口 | 先一个低风险写命令；同参数/同事件/同拒绝副作用；逐个接入并补工具+HTTP 双入口一致性 | 每命令独立回退；停新写者后用旧入口，不回滚事件日志 |
| 4 执行端口 | 先 DSH 适配现有 start/bind/end，四值 live 状态，迟到/重启/投递不确定负向断言；再单独选一个新宿主实测 | 保留 DSH 原派发路径；无新宿主任务活跃才撤适配，未知存活不强制解绑 |
| 5 技能与第二宿主 | 相同 role/gate 测试；宿主语法差异与降级矩阵；一条真实派发到 review 链路 | 技能入口可回旧版；事实数据仍由旧 DSH 可读写 |
| 6 可选 UI/发布 | 各宿主原生 UI 或文本，不以 Web/TUI 对等代替业务兼容；沿用平台发布门禁 | UI 可撤不改事实；发布 tarball 对账、保留原版本恢复通道 |

最小范围刻意不含 ops、worktree、存储、care runtime、工具注册、包拆分和格式升级；这能在未确定其他宿主 SDK 前独立验证纯提取。若需改变审批、状态、默认隔离或存储格式，应停止该阶段并让负责人裁决，而不是借“适配”静默改变语义。

## 5. 验证边界

本轮仅只读 Git/路径/文档检查；源码和测试保持基线字节不变。全量测试与构建**未在本轮运行**：既有 suite 有写夹具/构建，专属树初始无 dist/node_modules，安装/生成资产违反只读 recon brief。主管已确认此证据口径；不能将零代码差异写成“全量全绿”。未测试 Windows、新宿主、Mermaid/HTML 渲染、MCP 传输、事件跨宿主互写或崩溃恢复。设计是 Markdown 文本图，不交付可执行接口。

本轮实际只读检查：Python 标准库遍历四份设计文档的 78 个本地 Markdown 链接，核验文件与 `#L` 行范围；同一 checker 对内存注入的不存在文件、越界行锚点均拒绝，另断言 `git diff 80feee1 -- core/tests` 为空（共 81 项通过）。`node --input-type=module` 直接 import model/machine，8 项纯内存断言覆盖 roundtrip、判据识别、状态数、合法 review、非法直达 delivered、缺 rules_snapshot、blocked 缺原因及错误解除；无夹具/磁盘写入。`node --check dsh-graph-host/index.js` 与 `git diff --check` 通过。上述均为局部检查，不替代全量测试；完整断言命令保留在 attempt 工具记录。

实现前仍须原始全量测试 + 自证闸门、既有构建/平台验证；不更改测试来迁就重构。负责人裁决清单见 [契约草案](<v1.0.0-public-contract-draft.md>) 末节。
