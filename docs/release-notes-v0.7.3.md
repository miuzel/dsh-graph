# dsh-graph v0.7.3 Release Notes

> 发布日期：2026-09-01
> 前序版本：v0.7.2
> 主题：工程规范收敛、本地事务中间件、性能优化与数据刷新控制

## 本版本变更

- **上下文卡片与开发 Attempt 边界澄清（g-205）**：澄清主管行为指南中普通开发/实现目标使用 `graph_start_attempt(goal=..., worktree=true)`，明确卡片仅用于信息收集，`injected_cards: []` 不表示流程错误。
- **本地开发审查边界固化（g-206）**：固化单用户本地、owner-trusted 审查模型与四级输出（PASS/BLOCK/UNVERIFIED/OUT-OF-SCOPE），明确六项强制基线与边界外判定，规范自动化验证一轮后转人工复核。
- **统一本地事务与 REST Schema 校验（g-207）**：引入 `core/transaction.ts`（有限锁、CAS 重读与原子写）和 `core/schema.ts` 严格模式校验，迁移 settings 等关键端点，拒绝未知字段与隐式类型转换。
- **按变更风险收敛 Worktree 隔离策略（g-209）**：确立 main 分支只读、预建版本集成分支（`<version>-test`）及子代理不自行拉树铁律；提供只读审计与极小文档快速通道。
- **性能优化：Canonical Root 内存缓存（g-210）**：增加按工作区内存缓存与双重失效（TTL + `.git` mtime），彻底消除每个 REST 请求执行两次同步 `execSync(git ...)` 的开销，降低事件循环阻塞。
- **性能优化：Board 单次读与可见性感知（g-211）**：合并看板端点中 3 次事件流读取为单次复用；轮询降为 30s 并支持 `visibilitychange` 标签页后台自动暂停与切回补偿刷新。
- **自定义刷新间隔与倒计时微动效（g-214）**：设置面板支持自定义轮询间隔（5s 强制下限与持久化），数据时间旁提供局部秒级平滑倒计时与淡色微动效。
- **核心逻辑修复**：禁止 backlog 草稿直接阶段迁移（强制先排期）；`moveGoal` 移动到新版本时自动创建隐式版本元数据。

## 兼容性与升级

从 v0.7.2 升级无需数据迁移。既有 `.dsh-graph` 目标、卡片与事件流保持 100% 兼容。

## 发布边界

本次仅提交发布准备与版本分支合并，不执行 `npm publish`、`git tag` 或 `git push`。发布前请由负责人核验清单并手动执行发布命令。
